# Arkanoid_HTML
A simple, single-level version of the classic game Arkanoid, built with native web technologies and inspired by a spontaneous idea.

**You can play it online through the Github deployment**

## Introduction

This is a small, single-level arcade game inspired by Arkanoid, built with HTML, CSS, and plain JavaScript.

The game opens with instructions and starts when you press Space. Move the paddle with the left and right arrow keys or A and D. Press Space to pause or resume, and press it again after game over to play again.

There are no blocks in this first version. Keep the ball bouncing for as long as possible: each second of active play adds one point, and you begin with three lives.

To play, open `v0_bouncing_blockless/index.html` in a modern web browser, or use a local development server.

## About this game (some history)

Taito released Arkanoid in arcades in 1986, building on the paddle-and-ball formula that Atari had made popular with Breakout a decade earlier. In Arkanoid, players bounce a ball off a paddle to clear bricks, while power-ups and varied stages add new challenges. This project takes inspiration from that familiar idea but leaves the bricks and power-ups out: its open playfield is all about keeping the ball in motion and seeing how long you can last. It is a small learning project and an independent homage, not an official Arkanoid release.
